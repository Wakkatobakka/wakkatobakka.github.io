# Wakka’s Workshop

**Old games. New home.**

I’m Wakka. I get weird old phone games running on modern Android. This is the home for Omni Player, my game catalogues, the stories behind the bridges, and the other things I keep making.

**[Visit the workshop →](https://wakkatobakka.github.io/) · [Watch some gameplay](https://wakkatobakka.github.io/#gameplay)**

## Down the rabbit hole

- **[Omni Player](https://github.com/Wakkatobakka/Omni-Player)** — Supported old mobile games, together in one Android app. You supply the original game files.
- **[The catalogues](https://wakkatobakka.github.io/#catalogues)** — BREW, DoJa, ExEn, Zeebo, and J2ME. Searchable trails through the places and discoveries I collected while hunting for games, with links back to their sources.
- **[Bridges Before You Played Them](https://wakkatobakka.github.io/bridges-before-you-played-them/)** — What broke, how we fixed it, and the receipts. Cloud’s chest and Ghost Gun Leon included.
- **[The tool shed](https://wakkatobakka.github.io/#tools)** — Android Build Capsule, Artifact Passport, Workbench Continuity, and Retro Mod Pod. Things I made so I could keep making the other things.
- **[RIPPLE / The Living Archive](https://wakkatobakka.github.io/ripple/)** — Incident reports, cosmic horror, weird humor, and occasional kindness. Still being written.

I work with AI by directing, testing, and iterating, around my job and family. Mostly, I just think old things are neat.

This repository contains the website. Downloads, setup instructions, and project-specific credits live with the linked projects.
